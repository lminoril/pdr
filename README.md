# PDR Балашиха — Выпрямление вмятин на Вашем авто

Одностраничный сайт для бизнеса по удалению вмятин без покраски (технология PDR / Paintless Dent Repair).

**Что внутри:**
- 🎨 Светлая и тёмная тема (кнопка в шапке, выбор запоминается, по умолчанию — как в системе)
- 🚗 Главный экран с фото классического Мустанга в синих тонах и плавным «волновым» переходом
- ✨ Анимации при прокрутке: блоки плавно появляются каскадом, есть полоса прогресса чтения и лёгкий параллакс фона
- 🪪 Карточка мастера: круглое фото, имя, статус «PDR мастер» и факты
- 📸 Галерея работ «до и после» — 5 реальных работ, по клику фото открывается крупно (лайтбокс)
- 📖 О методе PDR и преимущества
- ⭐ Отзывы клиентов с Яндекс Карт (рейтинг, звёзды, тексты) и кнопка «Читать все отзывы»
- 📞 Контакты: телефон, VK, адрес, «как добраться»
- 🗺 Карта Яндекса: внизу страницы открывается ваша карточка организации с фото, отзывами и маршрутом
- 📱 Адаптивная вёрстка под телефоны, планшеты и компьютеры
