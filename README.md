# PDR Балашиха — Выпрямление вмятин на Вашем авто

Одностраничный сайт для бизнеса по удалению вмятин без покраски (технология PDR / Paintless Dent Repair).

**Что внутри:**
- 🎨 Светлая и тёмная тема (кнопка в шапке, выбор запоминается, по умолчанию — как в системе)
- 🚗 Главный экран с фото классического Мустанга в синих тонах и плавным «волновым» переходом
- ✨ Анимации при прокрутке: блоки плавно появляются каскадом, есть полоса прогресса чтения и лёгкий параллакс фона
- 🪪 Карточка мастера: круглое фото, имя, статус «PDR мастер» и факты
- 📸 Галерея работ «до и после» — 5 реальных работ, по клику фото открывается крупно (лайтбокс)
- 📖 О методе PDR и преимущества
- ⭐ Отзывы клиентов с Яндекс Карт (рейтинг, звёзды, тексты) и кнопка «Читать все отзывы»
- 📞 Контакты: телефон, VK, адрес, «как добраться»
- 🗺 Карта Яндекса: внизу страницы открывается ваша карточка организации с фото, отзывами и маршрутом
- 📱 Адаптивная вёрстка под телефоны, планшеты и компьютеры

## Как заменить фото на свои

Все фото лежат в папке `assets/img/photos/`. Просто положите файлы с нужными именами —
сайт автоматически покажет их вместо заглушек:

| Что заменить                       | Файл                            |
|------------------------------------|---------------------------------|
| Фото мастера                       | `assets/img/photos/master.jpg`  |
| Работа №1 (до и после в одном фото)| `assets/img/photos/work-1.jpg`  |
| Работа №2                         | `assets/img/photos/work-2.jpg`  |
| Работа №3                         | `assets/img/photos/work-3.jpg`  |
| Работа №4                         | `assets/img/photos/work-4.jpg`  |
| Работа №5                         | `assets/img/photos/work-5.jpg`  |
| Фон на главном экране              | `assets/img/hero-mustang.jpg`   |

Все фото работ сделаны в формате «слева ДО — справа ПОСЛЕ» в одном кадре, а подписи «ДО» и «ПОСЛЕ»
на сайте накладываются автоматически по краям. Когда будут новые фото, просто положите их
с теми же именами — и при необходимости отредактируйте подписи к работам в `index.html`
(блок `<div class="works-grid">`).

> Совет: сжимайте фото до ширины ~1200–1600px (можно бесплатно на squoosh.app или tinypng.com),
> чтобы страница грузилась быстро. Фото мастера лучше квадратное — оно показывается в круге.

## Отзывы и карта — как обновлять

На сайте всё связано с вашей карточкой организации в Яндекс Картах:

**Карточка:** https://yandex.ru/maps/org/udaleniye_vmyatin/137428932992/

- Внизу страницы карта показывает именно эту карточку (фото, отзывы, телефон, маршрут), а кнопки
  «Открыть карточку на Яндексе» и «Отзывы» ведут на неё и на вкладку отзывов.
- Блок «Что говорят о нас» — это **снимок** отзывов на момент публикации: рейтинг 4,3, 6 отзывов,
  показаны 3 последних. Автоматически подтягивать отзывы Яндекс не разрешает (для этого нужен
  платный API-ключ), поэтому тексты вписаны в файл.

Как обновить отзывы вручную (2 минуты):

1. Откройте `index.html`, найдите блок `<section class="section section-alt" id="reviews">`.
2. Рейтинг и количество: цифры `4,3` и `6 отзывов в Яндекс Картах`.
   Ширина заливки звёзд — в строке `<span class="stars-filled" style="width: 86%">`:
   4,3 из 5 → 86%, 4,5 → 90%, 5 → 100%.
3. Тексты: в каждой карточке `<article class="review-card">` есть имя (`review-author`),
   дата (`review-date`), звёзды и текст (`review-text`). Меняйте текст прямо между тегами.
4. Сохраните файл и загрузите его на GitHub — сайт обновится через минуту.

## 🚀 Как бесплатно опубликовать на GitHub (домен `ваш-логин.github.io`)

### Шаг 1. Заведите аккаунт
Зарегистрируйтесь на [github.com](https://github.com) (бесплатно, нужна только почта).

### Шаг 2. Создайте репозиторий
1. Нажмите зелёную кнопку **New repository** (или «+» в правом верхнем углу → New repository).
2. Назовите его, например: `pdr` или `vmyatiny` (латиницей).
3. Выберите **Public** (бесплатный хостинг работает только для публичных репозиториев).
4. **Не** ставьте галочку «Add a README file» — мы зальём свои файлы.
5. Нажмите **Create repository**.

### Шаг 3. Загрузите файлы сайта (способ без программ — прямо в браузере)
1. В открывшемся репозитории нажмите **uploading an existing file**.
2. Перетащите в окно содержимое папки проекта: `index.html`, папку `assets`, `README.md`.
3. Внизу нажмите **Commit changes**.

### Шаг 4. Включите GitHub Pages
1. В репозитории откройте **Settings** → слева **Pages**.
2. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
3. Нажмите **Save**. Через 1–2 минуты вверху появится адрес:

```
https://ВАШ-ЛОГИН.github.io/pdr/
```

Это и есть ваш бесплатный постоянный адрес. Вставьте его в Яндекс Бизнес,
Яндекс Карты, визитки и соцсети.

### Шаг 5. Как обновлять сайт
Откройте файл в репозитории → карандаш (Edit) → внесите правку → **Commit changes**.
Или загрузите новые фото кнопкой **Add file → Upload files**. Обновление появляется на сайте через 1–2 минуты.

### (Необязательно) Способ для продвинутых — через Git
```bash
git init
git add .
git commit -m "Первый запуск сайта"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/pdr.git
git push -u origin main
```

## Частые вопросы

**Домен бесплатный?**
Да, адрес вида `https://логин.github.io/название/` бесплатный навсегда, без рекламы.
Позже можно прикрепить свой домен (например, `pdr-balahiha.ru`) — Settings → Pages → Custom domain,
GitHub сам сделает бесплатный HTTPS-сертификат.

**Нужен ли сервер?**
Нет. GitHub Pages — это статический хостинг: файлы просто отдаются браузеру, сайт работает сам.

**Почему карта не грузится?**
Карта Яндекса подгружается с yandex.ru — нужен интернет (у посетителя, не у вас).
Если хочется другую точку на карте, поменяйте ссылку в `index.html` в блоке `<iframe ... yandex.ru/map-widget...>`.

**Фото фона на главной**
Сейчас используется снимок «Mustang» автора davejdoe (лицензия CC BY 2.0, указание автора — в подвале сайта).
Когда поставите своё фото в `assets/img/hero-mustang.jpg`, строчку с кредитом в подвале можно удалить.
